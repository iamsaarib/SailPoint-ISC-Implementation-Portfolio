# SailPoint Identity Security Cloud (ISC) Implementation Portfolio

Welcome! This repository showcases my structural knowledge and technical implementation capabilities within the **Identity Governance and Administration (IGA)** domain, specifically focusing on **SailPoint Identity Security Cloud (ISC)**. 

This portfolio contains sanitized, enterprise-grade engineering configurations designed to demonstrate foundational IAM architecture principles.

## 🛠️ Technical Competencies
* **Lifecycle Management:** Designing automated Joiner-Mover-Leaver (JML) identity states.
* **Custom Governance Logic:** Writing BeanShell/Java rules for account correlation and attribute calculation.
* **Data Integration:** Constructing configurations for authoritative sources, flat files, and target systems.
* **Least Privilege Enforcement:** Designing role structures and Separation of Duties (SoD) policies.

## 📂 Repository Contents
* `/rules` - Clean, sanitized Java/BeanShell rules demonstrating core SailPoint engineering logic.
* `/identity-profiles` - Architectural documentation of enterprise user identity maps.
